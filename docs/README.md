## Documentation Standards

All documentation files should:
- Use **lowercase with hyphens** for filenames (e.g., `my-guide.md`)
- Start with a clear overview section
- Include code examples where relevant
- Explain "why" decisions, not just "how"
- Stay up to date with code changes

When adding new documentation:
1. Follow the naming convention (lowercase-with-hyphens.md)
2. Add entry to this README
3. Keep it clear and concise
4. Include practical examples
5. Update related docs if patterns change
