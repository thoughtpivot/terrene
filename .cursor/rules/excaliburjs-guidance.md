# Cursor Rule: ExcaliburJS Documentation Guidance (0.32.x)

## Rule

-   **Always provide documentation and code guidance for ExcaliburJS version 0.32.x.**
-   When giving code examples, API usage, or troubleshooting, ensure all advice is accurate for ExcaliburJS 0.32.x.
-   If a user asks about a feature, bug, or upgrade, recommend using the latest patch release of 0.32.x if available, but do not recommend or use features from 0.33.0 or later.
-   Do not deviate from 0.32.x documentation or API guidance, even if newer versions exist.
-   When in doubt, reference the [ExcaliburJS documentation](https://excaliburjs.com/docs/).

## Rationale

-   This ensures all code and advice remains compatible with the project's locked engine version and avoids breaking changes from future releases.

---

_This rule is intended for all contributors, tools, and AI agents working in this codebase._
